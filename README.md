# Cleome (クレオメ)

> **暗号化シークレット保護・コマンドパレット・アクセス分析を備えた Chrome 拡張機能ブックマークマネージャー**

Cleome（クレオメ）は、日常の Web ブラウジングを快適かつ安全にするための高機能な Chrome 拡張機能（Manifest V3）です。
タグや説明、フォルダ階層による直感的な整理に加え、**「人に見られたくない秘密のブックマーク」を完全に隠蔽・保護し、Chrome のシークレットモードで自動起動する機能**や、Web 閲覧中にショートカットキーから呼び出せる **Raycast / Spotlight 風のコマンドパレット** を備えています。

---

## 🌟 主な機能

### 1. タグ・説明・フォルダによる柔軟な管理
- **タグ機能**: 複数タグの付与、チップ入力、タグクラウドからのワンクリック絞り込み。
- **説明・メモ**: 各ブックマークに詳細なメモや概要を記録可能。
- **フォルダ階層**: フォルダツリーによる整理・フィルタリング（親フォルダ選択時にサブフォルダも自動包含）。
- **リアルタイム検索**: タイトル、説明文、タグ、URL を対象とした高速インクリメンタル検索。

### 2. 特別なタグ「シークレット」とプライバシー保護
- **完全な隠蔽**: シークレットタグが付与されたブックマークは、通常のフォルダ一覧、タグ一覧、ダッシュボード、通常検索から**完全に除外**されます。
- **マスターパスワード保護**: 初めてシークレットタグを付与する際にマスターパスワードを設定（Web Crypto API の PBKDF2 / SHA-256 で安全にハッシュ化保存）。
- **シークレットモード自動起動**: シークレットブックマークを開く際は、**Chrome のシークレットウィンドウ（Incognito Window）** で自動的に開きます。

### 3. コマンドパレット（Content Script + Shadow DOM）
- **グローバル呼び出し**: 任意の Web ページ上で `Ctrl + Shift + K`（Mac は `Cmd + Shift + K`）を押すだけで、画面中央に美しいオーバーレイパレットが即座に起動。
- **キーボードナビゲーション**: `↑` `↓` キーでの移動、`Enter` で起動、`Esc` で閉じるストレスフリーな操作性。
- **シークレットアンロック**: パレット上の「シークレット解除」からマスターパスワードを入力することで、シークレットブックマークがアンロックされ検索・起動可能になります。
- **Shadow DOM 隔離**: 閲覧中の Web サイトの CSS やスクリプトと一切干渉しない完全独立設計。

### 4. ダッシュボード & アクセス統計
- ブックマークを開くたびにアクセス回数と最終アクセス日時を自動追跡。
- ダッシュボード上で「よく使うブックマーク TOP 5」「最近アクセスした項目」「総アクセス回数」をグラフ・メトリックカードで可視化。

### 5. インポート / エクスポート
- **独自形式 (JSON)**: タグ、説明、フォルダ、アクセス頻度、最終アクセスを含むすべてのメタデータを完全バックアップ・復元。
- **Chrome 標準形式 (HTML / Netscape Bookmark Format)**:
  - エクスポート時: タグ・説明・アクセス統計・シークレット情報をオミットした標準形式で書き出し。
  - インポート時: Chrome 等から書き出したブックマーク HTML のフォルダ階層と URL・タイトルを忠実に復元。

### 6. ツールバーポップアップ
- ブラウザのツールバーアイコンから、現在閲覧しているタブのタイトル・URL を自動取得してワンクリックでブックマーク保存（タグ、フォルダ、シークレット設定も可能）。

## 🛠 技術スタック

- **拡張機能仕様**: Chrome Extension Manifest V3
- **言語 / ビルド**: TypeScript, Vite 6, React 19
- **スタイリング**: Vanilla CSS（グラスモーフィズム、ダークテーマ、モダンデザイントークン）
- **セキュリティ**: Web Crypto API（PBKDF2, SHA-256, AES-GCM）
- **アイコン**: Lucide React

## 🚀 開発・インストール手順

### 前提条件
- Node.js (v18 以上推奨)
- Google Chrome

### 1. リポジトリのクローンと依存パッケージのインストール
```bash
npm install
```

### 2. プロダクションビルド
```bash
npm run build
```
ビルドが成功すると、`dist/` フォルダ内に拡張機能の成果物が生成されます。

### 3. Chrome への読み込み
1. Google Chrome を開き、アドレスバーに `chrome://extensions/` を入力して移動します。
2. 右上の **「デベロッパーモード」** を ON にします。
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本プロジェクト内の **`dist`** フォルダを選択します。

### 4. シークレットモード起動の許可（推奨）
シークレットタグが付いたリンクを Chrome のシークレットウィンドウで開くため、以下の設定を行ってください：
1. `chrome://extensions/` で Cleome のカードにある **「詳細」** をクリック。
2. **「シークレット モードでの実行を許可する」** のトグルを **ON** にする。

## ⌨️ ショートカットキー

| ショートカット | 動作 |
|---|---|
| `Ctrl + Shift + K` (Mac: `Cmd + Shift + K`) | 閲覧中の Web ページ上でコマンドパレットを開く / 閉じる |
| `↑` / `↓` | コマンドパレット内のアイテム選択移動 |
| `Enter` | 選択中のブックマークを開く |
| `Esc` | コマンドパレットを閉じる |

## 📜 スクリプト一覧

- `npm run dev`: ダッシュボード等のローカル開発サーバー起動
- `npm run build`: TypeScript 型チェックおよび Chrome 拡張機能（dist）のフルビルド
- `npm run pack`: フルビルドを実行し、Chrome Web Store 申請用の ZIP パッケージ（release/cleome-v1.0.0.zip）を自動生成
- `npm test`: 暗号化ハッシュ、シークレット除外、インポート/エクスポートの自動検証テスト
